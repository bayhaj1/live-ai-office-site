# Live AI Office — site de présentation

Site statique (FR / EN) de Live AI Office, tableau de bord de sécurité intelligent, local et privé, par POPEKI SURL.
Aucune donnée réelle : illustrations générées par IA (personnes fictives) et captures du mode démo.
Contact : Alex Nahimana · alex@popeki.com

Fichiers statiques uniquement (pas d'étape de compilation). Le site peut aussi être déployé sur Vercel, sur un nom de domaine personnalisé ; voir `vercel.json` pour les en-têtes de cache. Ne pas ajouter de JavaScript, de traqueurs ni de CDN.
